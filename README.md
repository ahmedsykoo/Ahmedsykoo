## Featured projects · أهم المشاريع

### [AR Termux](https://github.com/ahmedsykoo/ar-termux)
Termux with proper Arabic / Hebrew / Persian / Urdu rendering — connected letters, correct RTL order, works with Claude Code and OpenCode.
ترمكس بدعم عربي صحيح: حروف متصلة واتجاه سليم.
`Android` `Terminal` `RTL` `Shell`

### [RTL Terminal](https://github.com/ahmedsykoo/ar-terminal)
VS Code extension that renders Arabic, Hebrew, Persian and Urdu correctly in the integrated terminal. Contributed Persian & Urdu character support.
`TypeScript` `VS Code`

### [So-Key AI](https://github.com/ahmedsykoo/So-key-ai)
AI chat app (React + Vite + Tailwind + Capacitor) with a full design pack and Android build pipeline.
`TypeScript` `React` `Capacitor`
